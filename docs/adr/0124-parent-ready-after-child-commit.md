# 0124. Передача родителя в сборку — своей транзакцией после закрытия ребёнка

- **Дата:** 2026-10-24
- **Статус:** принято

## Контекст

Переход «незавершённых детей не осталось» делает воркер, закрывший последнего ребёнка
([0069](0069-parent-phase-column.md)): условное обновление родителя
`AWAITING_CHILDREN → PENDING` с `NOT EXISTS` незавершённых детей его попытки раскрытия. Не сказано,
в какой транзакции. Детей у родителя бывает миллион, закрываются они параллельно.

## Рассмотренные варианты

- **A. В транзакции закрытия ребёнка** — отвергнуто. Два последних ребёнка, закрытые одновременно
  в `READ COMMITTED`, не видят незакоммиченных изменений друг друга: каждый находит другого
  незавершённым, и переход не делает никто. Родитель застревает до подстраховочного поллера.
- **B. То же, но с блокировкой строки родителя** — отвергнуто. Закрытие каждого ребёнка
  сериализуется на одной строке: миллион подзадач группы закрывались бы по одной.
- **C. Своей транзакцией после коммита закрытия — выбрано.** Каждый ребёнок проверяет уже после
  своего коммита; последний закоммитившийся видит коммиты всех остальных и переход делает.
  Переход условен по статусу, второй выполнивший его ничего не меняет.

## Решение

После коммита, закрывшего попытку группы или подзадачи, воркер — и переподхват, закрывший
брошенную попытку ребёнка, — выполняет переход родителя отдельной короткой транзакцией. Так же,
после коммита и своими транзакциями, идут остальные шаги каскада: перевод детей закрытой попытки
раскрытия из `AWAITING_PARENT` и удаление результатов детей в режиме `immediately`.

Ошибка шага каскада закрытия не отменяет. Шаг, не выполненный из-за падения между коммитом
и каскадом, доводит подстраховочный поллер.

## Последствия

- На каждое закрытие ребёнка — ещё одна короткая транзакция с `EXISTS` по индексу
  `(parent_attempt_id, status)`, обычно находящая незавершённого соседа сразу.
- Строка родителя не блокируется ни при закрытии детей, ни при проверке.
- Окно между коммитом и каскадом — новый случай для подстраховочного поллера, наравне
  с прерванным переводом детей ([0068](0068-expansion-children-statuses.md)).
