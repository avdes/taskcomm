# 0118. Настройки попыток — по методу процессора, а не по фазе

- **Дата:** 2026-10-24
- **Статус:** принято

## Контекст

Настройки аренды и повторов разрешаются по пяти уровням, и третий из них — аннотация на методе
процессора ([0061](0061-processor-configuration-annotations.md)). Ключом разрешения при этом
названа пара «тип и фаза». У группового процессора фазе отвечает не один метод: раскрытию —
`expand` и `expandBatch`, сборке — `collect` и `collectBatch`. Аннотации на этих методах могут
расходиться, и пример самого 0061 — двухчасовой предел на `expandBatch` при коротком `expand`.

## Рассмотренные варианты

- **A. Ключ — тип и фаза, расхождение аннотаций двух методов фазы — падение при старте** —
  отвергнуто. Пример из 0061 задаётся тогда только через `yaml`, и предел ложится сразу на оба
  метода: `expand` получает два часа, которые ему не нужны.
- **B. Ключ — тип и метод — выбрано.** Метод однозначно определяется уровнем сущности и фазой
  попытки.

## Решение

- **Настройки попыток разрешаются по типу задачи и методу процессора.** Метод — это пара «уровень
  сущности, фаза попытки»: `process` задачи, `expand`, `expandBatch`, `process` подзадачи,
  `collectBatch`, `collect`.
- **Аннотация на методе действует только на свой метод.**
- **Фаза в `yaml` (`types.<тип>.phases.<фаза>`) покрывает все методы фазы.** Схема `yaml`
  не меняется.
- Печать итоговых настроек при старте идёт по типам и методам, с уровнем каждого значения.
- Приоритет по-прежнему только на уровне типа ([0084](0084-priority-only-per-type.md)).

## Последствия

- Пример из 0061 выражается аннотацией на `expandBatch`, не задевая `expand`.
- `yaml` точечно до одного метода фазы не достаёт: эксплуатация переопределяет фазу целиком.
  Понадобится точнее — добавится уровень метода в `yaml`, аддитивно.
- Heartbeat один на экземпляр, а интервал свой у метода: поток тикает с самым коротким итоговым
  интервалом и продлевает каждую попытку по интервалу её метода. Предел обработки в продлениях
  от этого не тратится быстрее задуманного.

## Связанные решения

- [0061](0061-processor-configuration-annotations.md) — пять уровней разрешения.
- [0084](0084-priority-only-per-type.md) — приоритет только на уровне типа.
- [0025](0025-lease-mechanics.md), [0103](0103-heartbeat-not-shorter-than-lease-fails.md) —
  heartbeat и проверка интервала по каждому итоговому значению.
