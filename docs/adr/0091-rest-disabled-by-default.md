# 0091. REST выключен по умолчанию

- **Дата:** 2026-10-20
- **Статус:** принято

## Контекст

[0014](0014-rest-api.md) дал REST API под `taskcomm.rest.base-path` с выключателем
`taskcomm.rest.enabled`, по умолчанию включённым, и сознательно не тронул Spring Security:
стартер отдаёт `RequestMatcher`, а вписать пути в свою конфигурацию должен потребитель.

В составе API — чтение нагрузок и поиск по ним, создание задач и коммуникаций, перезапуск, отмена,
история обмена с телами запросов и ответов ([0055](0055-communication-exchange-storage.md)).
В телах и заголовках легко оказаться персональным данным и токенам.

Подключил стартер — и в приложении появились эндпоинты, которые отменяют задачи, отправляют
сообщения во внешние системы и отдают чужой обмен. Защищены они ровно настолько, насколько
потребитель о них знает: без Spring Security — открыты всем, кто достучится до порта; с ним —
обычно закрыты общим «всё требует аутентификации», и любой пользователь приложения получает право
отменять чужое и читать чужое. Ровно поэтому Actuator по умолчанию открывает через веб только
`health`.

## Рассмотренные варианты

### A. Выключен по умолчанию — выбрано

Потребитель включает REST явно и в этот момент читает, что пути надо закрыть.

### B. Включён, по умолчанию только чтение — отвергнуто

Изменяющие операции отдельным свойством. Но чтение тел обмена и нагрузок остаётся открытым,
а это самое чувствительное.

### C. Включён, только если в classpath есть Spring Security — отвергнуто

Поведение стартера зависит от чужой зависимости, а наличие Security не значит, что пути закрыты
как надо.

### D. Оставить включённым — отвергнуто

## Решение

- **`taskcomm.rest.enabled` по умолчанию `false`.** Подсистема REST подчиняется и корневому
  выключателю ([0090](0090-root-switch-disables-everything.md)).
- Бин `RequestMatcher` с путями стартера создаётся вместе с REST — то есть тоже только при
  включённом REST.
- Javadoc свойства и документация потребителя обязаны сказать при включении: пути надо закрыть
  в своей конфигурации безопасности, стартер этого не сделает
  ([0014](0014-rest-api.md)).

## Последствия

- **Подключение стартера не открывает ничего наружу.** Опасное по умолчанию исчезает.
- **REST включают одной строкой**, и для UI, который на нём держится, это обязательный шаг
  настройки.
- Критерии готовности этапа REST и тесты автоконфигурации проверяют обе стороны: по умолчанию
  контроллеров нет, при `enabled: true` — есть.
- Значение по умолчанию выбрано до первого выпуска, поэтому правило «новое свойство сохраняет
  прежнее поведение» не нарушено: прежнего поведения у потребителей ещё нет.

- [0090](0090-root-switch-disables-everything.md) — корневой выключатель.
- [0055](0055-communication-exchange-storage.md) — тела обмена, которые отдаёт REST.
